# examples/

Fixture homespaces used by the test suites — small, complete homespace folders
(`homespace.manifest.jsonc` + `content/packs/…`) that scanner, renderer, and CLI
tests build and snapshot against.

Populated as work orders land (scanner fixtures in WO-2, golden-output fixtures
in WO-3/WO-5). See `internal-docs/HomespaceTDD.md` §10.
