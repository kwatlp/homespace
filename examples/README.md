# examples/

Fixture nodes used by the test suites — small, complete node folders
(`node.manifest.jsonc` + `content/packs/…`) that scanner, renderer, and CLI
tests build and snapshot against.

Populated as work orders land (scanner fixtures in WO-2, golden-output fixtures
in WO-3/WO-5). See `internal-docs/KwatlpTDD.md` §10.
